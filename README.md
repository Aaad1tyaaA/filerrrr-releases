# Filerrrr

Windows x64 desktop file conversion with a matrix palette, progress, Cancel/Undo, presets, watch folders and focused editors.

**No app login. No account needed to convert files. No AI tools. English-only GUI.**

Download the `.exe` installer from [Releases](https://github.com/Aaad1tyaaA/filerrrr-releases/releases). This repository holds installers, checksums and release notes; development source is maintained separately.

Releases are intentionally unsigned. No paid signing certificate is required to install or use Filerrrr. Windows may show an unknown-publisher or SmartScreen warning. Updates use manual installer downloads from this release page; the app does not automatically install unsigned updates.

The Full installer bundles the existing offline engines. Optional external format applications remain separate. See each release's notes for limitations and validation evidence.
