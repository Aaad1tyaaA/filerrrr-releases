# Filerrrr

Windows x64 desktop file conversion, with a matrix palette, progress, Cancel/Undo, presets, watch folders and focused editors.

**No app login. No account required to convert files. No AI tools. English-only GUI.**

Download the installer from [Releases](https://github.com/Aaad1tyaaA/filerrrr-releases/releases). This repository holds installers, checksums and release notes. Development source is not maintained in this repository.

Preview builds are unsigned until a publisher certificate is issued. Automatic update downloads stay disabled in unsigned previews. Future signed builds will check the release feed and verify the publisher's Windows signature before installation, with restart controlled by the user.

The Full installer bundles the existing offline engines. Optional external format applications remain separate. See each release's notes for limitations and test evidence.
